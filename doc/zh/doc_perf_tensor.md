# doc_perf_tensor.md

## TL;DR

数据来源: [perf_tensor.json](../../src/test/perf/perf_tensor.json)

测试环境:  
- CPU AMD 9955HX
- MEMORY DDR5 16G*2 5600Mhz
- Windows11家庭版
- C++17
- CMake 4.3.1
- Google benchmark 1.9.5

测试项目:  
Tensor类默认构造函数，无填充构造函数，有填充构造函数(由4KiB到128KiB)，拷贝构造函数，加法运算符重载(由4KiB到16KiB)
Matrix类默认构造函数，无填充构造函数，有填充构造函数(由4KiB到128KiB)，拷贝构造函数，加法运算符重载(由4KiB到16KiB)

核心结论:  
Tensor类由于成员变量，构造逻辑等因素，整体慢于Matrix。  
对于填充构造逻辑，Tensor慢于Matrix，但经过向量化后，尤其是大数据量下差距逐渐缩小，甚至某些情况下反超。  
拷贝构造函数中，Tensor快于Matrix主要是因为Matrix的构造逻辑多了一步为vector填充0。  
加法运算符重载中，Tensor快于Matrix是因为Tensor实现了移动语义，最后返回结果时效率更高。
