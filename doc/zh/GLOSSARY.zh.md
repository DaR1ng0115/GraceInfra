# GLOSSARY / 中英文术语对照表

该文档列出了在本章节中出现的中英文术语解释，便于读者理解。

| 原词 | 英文 | 解释 |
| :---: | :---: | :---: |
| 张量 | Tensor | 张量是一个多维数组，可以看作是标量、向量和矩阵的推广。<br>张量的阶数表示其维度的数量，例如标量是0阶张量，向量是1阶张量，<br>矩阵是2维张量。张量在深度学习中用于表示数据和模型参数。 |
| src | Source | 源代码目录，通常包含项目的主要代码文件。 |
| 行 | row | 在张量中，通常指的是二维数组中的一行数据。 |
| 列 | column | 在张量中，通常指的是二维数组中的一列数据。|
| git忽略文件 | .gitignore | 用于指定Git在版本控制中应忽略的文件或目录。 |
