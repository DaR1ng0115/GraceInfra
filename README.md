## 导论
1. 为什么这一章的主题是buffer&template ?
在上一章中，我们实现了tensor的基本骨架，但并不完整，深度学习中重要的tensor功能，比如视图机制，任意维度访问等均没有实现，而想实现这些，我们就需要借助buffer和template，至于为什么这两个能实现上述的功能，请见下文。
2. buffer是什么？
buffer是一种数据容器，它的职责专用于管理数据，而不负责这个数据包含的语义是什么。简单来说，在buffer里，你只能看到一个连续的一维数组，数组中拥有的元素数量，而看不到维度是怎么样的。这便是抽象分层，将纯数据结构从tensor中解耦出来。  
那我们再往下推一层，假设Tensor A为(3, 2)，Tensor B为(6)，两者的背后都是六个元素的一维数组，如若它们的数据是一样的，那我们应该怎么去优化这种情况？这个时候buffer的作用就体现出来了，buffer不管你数据是怎么访问的，它只管理那个一维数组，因此A和B可以共用同一个buffer，但问题来了，两个Tensor共用一个buffer，如果A对象析构了，buffer应该析构吗？答案是不行，因为还有一个B对象指向了这个buffer，解决办法就是:引用计数。当A对象和B对象指向同一个buffer对象的时候，其引用计数为2，A对象析构，引用计数减一，B对象析构，引用计数变为0，这个时候没有任何对象指向这个buffer，因而其应该析构。
3. template是什么？
template是一种语法，它让我们的函数，变量可以是不定的类型，可以是double，也可以是float，甚至float8等，其实跟我们在数据结构中看到的`ElemType`宏是类似的。当然模版的威力远不止这些，实现tensor任意维度的访问，即使用可变参数模版。
